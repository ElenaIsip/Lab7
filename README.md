# Разбор по шагам:
Объявление переменной char c — для хранения одного символа.

Вывод приглашения printf("Введите символы 'a' or 'b': ").

Считывание символа с консоли через scanf("%c", &c).

Конструкция switch (c) проверяет значение c:

* если c == 'a' → выводится "Введено 'a'.", затем break (выход из switch);

* если c == 'b' → выводится "Введено 'b'.", затем break;

иначе (любой другой символ) → срабатывает default → выводится "Неизвестный символ".

return 0; — завершение программы.

# Особенности работы
scanf("%c", ...) читает ровно один символ, включая пробел, табуляцию и перевод строки (\n).

Если пользователь нажмёт Enter, не введя символ, то будет прочитан '\n', и сработает ветка default → "Неизвестный символ".

Регистр важен: 'A' и 'B' не совпадут с 'a' и 'b', поэтому тоже попадут в default.

Если ввести строку из нескольких символов (например, abc), будет прочитан только первый символ 'a' — остальные останутся в буфере ввода.
